# Personal Portfolio Website

A modern, responsive, and user-friendly personal portfolio website designed to showcase my background, technical skills, projects, and experience as a Computer Science graduate and Full Stack Developer.

This portfolio serves as a central place to learn more about me, explore the web applications and systems I have developed, and view the technologies and tools I work with.

The website highlights my experience in frontend and backend development, database management, API integration, and IT support. It also provides links to my GitHub, LinkedIn, resume, and contact information for potential employers, clients, and collaborators.

## 🎯 Purpose

The goal of this portfolio is to showcase my development journey, demonstrate my practical projects, and provide an overview of the technologies and skills I use to build real-world applications.

I am continuously learning and improving my skills while building projects that solve practical problems.
